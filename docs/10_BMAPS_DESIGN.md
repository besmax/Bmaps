# Bmaps design system

The user-supplied Stitch Bmaps specification defines the visual system. `core:ui/theme/BmapsTheme.kt` owns the complete dark color palette, a derived light palette, Inter typography, and Material shapes. `AppShell` applies it around every destination and dialog while preserving the existing device/light/dark preference.

The supplied named color table takes precedence where the prose uses different shades. Primary containers use Trail Amber (#FF6B35); primary action buttons explicitly use that container with white labels as requested. Confirmation uses secondary colors and size estimates use tertiary colors. Light mode derives neutral surfaces and darker foreground accents from the supplied palette. All fixed color roles remain the supplied values.

Inter 4.1 Regular, SemiBold, and Bold are bundled as static font resources, so typography works offline on Android and iOS. Its SIL Open Font License is bundled in `core/ui/src/commonMain/composeResources/files/inter_license.txt`. The upstream distribution is https://github.com/rsms/inter/releases/tag/v4.1.

Typography maps the supplied headline, title, body, and label styles to Material typography roles. `headlineLarge` is 26/32 sp below 600 dp and 32/40 sp on larger surfaces. `displayMedium` is the 28/32 metric display style and `displaySmall` is the 18/22 compact metric style. Tabular figures are enabled for all styles. Font sizes and line heights use sp; em letter spacing preserves the specified relative tracking.

Shapes use 8, 16, 24, 32, and 48 dp corners. Floating controls and primary buttons use full circular/stadium shapes with at least 48 dp touch targets. Screen margins are 16 dp below 600 dp and 24 dp on expanded layouts. Non-map content is centered within a 720 dp width; floating map panels cap at 360 dp and the expanded-layout selection action docks at the bottom right.

Map chrome uses translucent surface tiers, subtle borders, and elevation shadows. `core:ui` owns `MapIconButton` and shared Back/zoom/layers icons; online and offline maps use the same translucent icon-button styling with localized accessibility labels and at least 48 dp targets. The implementation does not apply a true backdrop blur: foreground blur would blur controls rather than the map behind them, and no new rendering dependency is introduced for that effect. Online attribution remains visible and linked. Offline attribution is accessed through a bottom-right info icon that opens a scrollable dialog with source text, URLs, and Open link actions. Phase 6 removes navigation bars. The home library uses an amber constructor FAB, a top-bar gear, and vector package avatars; the viewer uses floating map controls and Back navigation.

The area selector retains its ViewModel-owned movement and resizing behavior. Its visual treatment is a 12% amber fill, a 2 dp amber boundary, and 8 dp corner circles within 48 dp gesture targets. Instructions use a translucent rounded surface. No dummy search, recording, telemetry, offline-ready, or 3D controls are introduced for unimplemented features. Current location adds a functional My location icon, a blue dot with a white border, and a translucent accuracy circle on online and offline maps; location acquisition and failures use a persistent localized notice with progress and Retry/Settings actions, accompanied by snackbars for one-off messages.

Builds, device previews, and runtime testing are left to the user at their request.

Phase 7 adds provider selection, ordering, and visibility controls to constructor settings and a floating layers `MapIconButton` to the offline viewer. Download zoom uses a two-thumb integer range slider with inclusive endpoints. Lists run from bottom to top, with Raise/Lower actions and visibility checkboxes. Independent opacity sliders appear only in the offline viewer; downloads initialize opacity to 100%. Viewer edits preview after a slider gesture; Save writes the settings and Cancel restores the committed appearance. Attribution includes every package source. Labels use feature string resources and Material theme roles.

Phase 8 adds a Map objects panel to the offline viewer, with marker/line/polygon creation and visibility controls. Drawing uses map taps and a bottom toolbar with Undo, Finish, and Cancel. Properties offer names, descriptions, per-object color swatches, a catalog-generated SVG marker picker, and vertex move/remove controls. Vector placemarks have 48 dp click targets. Save commits the draft; Cancel leaves stored data unchanged. Details and deletion confirmation remain separate from drawing.

A saved placemark waiting for a destination morphs over 280 ms into three overlapping circles tinted with its object color. Different radii, opacity, and orbiting centers make the 2.6-second repeating motion visible. Its geographic anchor stays fixed, and leaving move mode reverses the transition. The marker exposes the destination instruction as its accessibility state description. Motion remains local to the marker's draw phase. Device appearance and performance acceptance remain with the user.

Settings uses its own top app bar and Back action. Theme choices use a single-choice System/Light/Dark segmented control; map preferences and the About/licensing content are grouped in cards. Settings apply independently without Save/Cancel. Portrait uses a centered scrolling stack; landscape windows of at least 600 dp use separate scrolling columns for Appearance/About and map settings. About displays the installed native version code. See `7_FEATURE_SHELL.md`.

The offline center readout wraps its content and sits centered at the bottom. Portrait uses up to two rows; landscape uses a single line with ellipsis for constrained width. Its content is: the existing formatted coordinate row and optional altitude as `H: 27.3 m`. Accuracy, epoch and vertical-reference annotations are omitted to reduce map obstruction. A vertical parallel two-finger swipe hides all application controls and widgets; repeating it restores them. The map, annotation geometry and GPS marker remain visible and pinch zoom/pan remain available. The map offers the same toggle as an accessibility action. See `13_LIBRARY_AND_OFFLINE_VIEWER.md` for gesture and session behavior; native appearance and interaction acceptance remain with the user.

Offline map controls use 48 dp targets and 8 dp gaps within groups. Landscape keeps a compact right-side column that scrolls on short screens. Portrait distributes three groups along the right edge: layers at the top opposite Back, zoom centered vertically, and current location/attribution at the bottom, respecting safe drawing insets and 16 dp edge margins. Bottom content reserves symmetric space for this rail in both orientations.
